name: Future content generation
description: Scope rule for improving generated sales and PR copy without rewriting approved historical content.
---

Keep existing approved email templates and historical PR-FREE article text unchanged unless the user explicitly asks to rewrite them. Apply content-quality and factuality improvements to newly generated content.

**Why:** The user confirmed that the current copy is acceptable and asked to fix what is generated from now on, starting with email generation.

**How to apply:** Treat existing database records as preserved history. For future generation, use registered business facts only and reject invented performance, pricing, guarantees, partnerships, coverage, rankings, or numerical effects. Do not extend changes to PR-FREE generation unless requested.
